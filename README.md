# Aero Launcher

A native Android launcher starter built with Kotlin + Jetpack Compose. It uses an iOS-inspired visual language: translucent surfaces, a calm gradient wallpaper, a rounded dock, spacious typography and an App Library.

## Included
- Home screen with gradient wallpaper, greeting and search entry
- App grid populated from installed launcher apps
- App Library with live filtering
- Automatically organized premium-style folders (Social, Photos & Media, Games, Shopping, Finance, Productivity, Communication and Utilities)
- Folder preview tiles with app icons and one-tap folder browsing
- Launch installed apps
- Rounded translucent dock
- Settings dialog with large-icon and greeting toggles
- Can be selected as the Android default Home app

## Build
1. Install Android Studio (Ladybug or newer) and Android SDK 35.
2. Open this folder in Android Studio.
3. Let Gradle sync, then Run on an Android device or emulator.
4. Press the Android Home button and choose **Aero Launcher**; select Always to make it your default launcher.

## Notes / next development steps
This is a functional starter, not a finished commercial launcher. Android launchers need additional device-specific testing for widgets, gesture navigation, icon badges, wallpaper picking, notification access and accessibility. The current app list and settings are intentionally simple. The status indicators are decorative.

Suggested premium roadmap:
- Icon packs and per-app icon editing
- Custom grid size, icon labels and folder management
- Wallpaper picker, parallax and blur controls
- Gesture actions (swipe down for notifications, double-tap to lock where supported)
- Calendar, weather and battery widgets
- Hidden apps with biometric/app-lock integration where permitted
- Backup/restore of launcher layout
- Paid theme packs and optional one-time Pro unlock

Do not advertise features as implemented until they are built and tested.
